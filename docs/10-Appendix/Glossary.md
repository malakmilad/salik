## Platform & Marketplace Terms

| Term | Definition |
|------|------------|
| **Acceptance rate** | Percentage of offer invitations a provider accepts. Target: ≥70%. |
| **Active job** | A service request from offer acceptance through completion or cancellation. |
| **Active provider** | A verified provider with at least one available vehicle and ≥1 completed job in the last 30 days. |
| **B2B** | Business-to-business; jobs routed through insurance, fleet, or enterprise partners. |
| **B2B2C** | Business-to-business-to-consumer; partner (e.g., insurer) provides end customer access to Salik Assist. |
| **B2C** | Business-to-consumer; direct customer relationship via Salik Assist app. |
| **Commission (take rate)** | Percentage of job value retained by Salik Assist. Standard: 18%. |
| **Completion rate** | Percentage of accepted jobs that reach successful completion. Target: ≥95%. |
| **Customer** | Motorist or authorized vehicle operator using Salik Assist to request roadside assistance. |
| **ETA (Estimated Time of Arrival)** | Provider's committed arrival time shown in offer; SLA: ±15 minutes. |
| **GMV (Gross Merchandise Value)** | Total value of completed jobs (customer payments) before platform deductions. |
| **Guest checkout** | Emergency request flow without full account registration; limited to 2 jobs. |
| **Job** | A single roadside assistance service request from submission to completion/cancellation. |
| **Matching** | Process of identifying and inviting eligible providers for a customer request. |
| **Marketplace** | Two-sided platform connecting customers with independent providers; Salik Assist does not perform services. |
| **Net revenue** | Platform revenue after provider payout; includes commission, subscriptions, and B2B fees. |
| **No-show** | Provider accepted job but failed to arrive or go en route within 15 minutes. |
| **Offer** | Provider's response to a request invitation including ETA, price, and availability. |
| **Provider** | Independent roadside assistance business registered and verified on Salik Assist. |
| **Provider pool** | Set of eligible, available providers within matching radius for a request. |
| **Request** | Customer's submitted service need including location, category, and vehicle info. |
| **Salik Assist** | The marketplace platform brand connecting motorists with verified roadside providers in GCC. |
| **Salik Performance Score (SPS)** | Composite provider quality score (0–100) based on rating, ETA, acceptance, and completion. |
| **Top-3 offer model** | Customer receives up to 3 competitive provider offers before selecting one. |
| **Verification badge** | Customer-facing indicator that provider passed Salik Assist credential checks. |

## Roadside Assistance Service Terms

| Term | Definition |
|------|------------|
| **Battery jump-start** | Providing electrical boost to start vehicle with depleted battery. |
| **Battery replacement** | Installing new battery; typically includes 30-day provider warranty. |
| **Call-out fee** | Charge applied when provider arrives but service not completed (cancellation at arrival stage). |
| **Desert recovery** | Specialized vehicle extraction from off-road/desert terrain; premium pricing. |
| **EV rescue** | Emergency electric vehicle charging or specialized EV tow to charging station. |
| **Flatbed tow** | Towing with entire vehicle loaded on flat bed; preferred for AWD/EV. |
| **Fuel delivery** | Emergency delivery of petrol or diesel to stranded vehicle. |
| **Highway recovery** | Service performed on highway/emergency shoulder; may include surcharges. |
| **Lockout** | Assisting customer locked out of vehicle; non-destructive entry preferred. |
| **Mobile mechanic** | On-site minor repair and diagnostics without towing to garage. |
| **Recovery** | General term for vehicle retrieval including tow and winch extraction. |
| **Roadside assistance** | Umbrella term for emergency vehicle services at breakdown location. |
| **Tire change** | Replacing flat tire with spare or temporary repair. |
| **Tow (towing)** | Transporting immobilized vehicle to specified destination via tow truck. |
| **Wheel-lift tow** | Towing with front/rear wheels lifted; common for short-distance urban tows. |
| **Winch extraction** | Pulling vehicle from ditch, sand, or stuck position using winch cable. |

## Operations & Policy Terms

| Term | Definition |
|------|------------|
| **Activation** | Point when verified, trained provider becomes eligible for customer offers. |
| **Appeal** | Provider or customer request to review suspension, rejection, or refund decision. |
| **Auto-remedy** | System-applied SLA compensation (credit/refund) without customer request. |
| **Cancellation stage (S0–S4)** | Job lifecycle point determining cancellation fee (see Cancellation Policy). |
| **Conditional approval** | Verification status with minor documentation gaps; 14-day remediation. |
| **Escalation** | Elevation of issue to higher support/ops tier per severity (P1–P4). |
| **Force majeure** | Declared event (severe weather, road closure) suspending SLA obligations. |
| **Manual dispatch** | Operations team manually securing provider when automated matching fails. |
| **Mystery shop** | Salik-contracted test request to evaluate provider quality anonymously. |
| **Offboarding** | Provider departure from platform; voluntary or involuntary. |
| **Onboarding** | Process from provider application through verification, training, and activation. |
| **P1–P4 severity** | Escalation priority levels: P1 Critical (5 min response) to P4 Low (4 hr). |
| **Performance review** | Formal evaluation triggered by SPS drop, complaints, or policy violations. |
| **Quality flag** | Automated alert on low rating, keyword, or audit failure triggering review. |
| **Re-dispatch** | Assigning new provider when original provider cancels, no-shows, or is delayed. |
| **Service credit** | Platform balance applied to future jobs; alternative to cash refund (120% option). |
| **SLA (Service Level Agreement)** | Documented time and quality commitments with defined remedies. |
| **Soft launch** | Limited release (invite-only) before public availability. |
| **Suspension** | Temporary provider deactivation from matching pool pending investigation. |
| **Tier 1/2/3 verification** | Standard, Premium, and Partner verification levels with increasing rigor. |

## Financial Terms

| Term | Definition |
|------|------------|
| **AOV (Average Order Value)** | Average customer payment per completed job. UAE target: AED 181–197. |
| **Break-even** | Point where monthly contribution margin covers fixed costs. Target: Month 22–26. |
| **CAC (Customer Acquisition Cost)** | Marketing spend divided by new customers acquired. Target: AED 35–45 mature. |
| **Contribution margin** | Platform revenue minus variable costs per job. Target: ≥12% of GMV. |
| **Fixed costs** | Monthly costs not varying with job volume (team, office, base marketing). |
| **Gross margin** | Net revenue minus cost of revenue. Target: 72% Y1 → 82% Y3. |
| **LTV (Lifetime Value)** | Total contribution margin from customer over relationship. Target: AED 63 by Y3. |
| **LTV:CAC ratio** | Return on acquisition spend. Target: ≥3:1 with subscription. |
| **Payout (provider)** | Transfer of job earnings to provider bank account. Standard: T+2 business days. |
| **Pre-authorization** | Temporary hold on customer payment method up to 120% of estimate. |
| **Remedy reserve** | Budget allocation (1% GMV) for SLA breach compensation. |
| **SAM (Serviceable Addressable Market)** | Revenue opportunity in target geography and segments. UAE: AED 660–880M. |
| **Surge pricing** | Dynamic price increase during high demand; capped at 2.5× base. |
| **Take rate** | See Commission. |
| **TRN (Tax Registration Number)** | UAE VAT registration identifier. |
| **Unit economics** | Per-job or per-customer profitability analysis. |
| **Variable costs** | Per-job costs: payment processing, support, remedies, verification amortization. |

## Business Examples

**Example 1 — Using glossary in support:** Customer asks "What is a call-out fee?" Agent references glossary: charge at cancellation stage S3 (provider arrived). Applies Cancellation Policy: AED 75 unless exception trigger met.

**Example 2 — Investor conversation:** Investor asks difference between GMV and net revenue. Glossary definitions: GMV = total customer payments (AED 154M Y3); net revenue = platform share (AED 27.9M Y3) including commission, subscriptions, B2B fees.

**Example 3 — Provider onboarding:** New provider asks "What is SPS?" Trainer references glossary and Provider Performance doc. SPS 75+ needed for Preferred tier commission discount.
